# Code of conduct

## Our standard

This project exists to help engineers reason about correctness in systems that
move money. Discussion should be technical, specific, and civil.

Expected behaviour:

- Critique designs, code, and claims — not people.
- Assume the other person has context you do not.
- When you correct something, cite a source.
- Accept correction the same way.

Unacceptable behaviour:

- Personal attacks, harassment, or demeaning comments.
- Posting anyone's private information.
- Sustained disruption of discussion.
- Sharing real cardholder data, credentials, or another organization's
  confidential material in any issue, pull request, or comment.

## Scope

This applies to issues, pull requests, discussions, and any other project
space.

## Enforcement

Report unacceptable behaviour by opening an issue, or by asking in an issue for
a private contact channel if the report should not be public. Reports will be
reviewed and acted on, which may include editing or removing content and
blocking accounts from the repository.

## Attribution

This code of conduct is adapted in spirit from the Contributor Covenant, and
kept short deliberately so it is actually read.
