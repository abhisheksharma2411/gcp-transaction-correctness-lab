## Negative controls

Every finding code has to be provoked by a named defect, and each control
must produce its stated codes and no others. A control blunt enough to
redden several unrelated checks is rejected, because "I broke it and the
checker complained" is not evidence that any particular check works.

## Projection rebuild

The read model is rebuilt from the event log twice: once in order, once
from the reversed log. A projection that depends on the order the events
are read in is not a projection of the events.

```
forward:  ord-a@1:[sku-1];ord-b@2:[sku-3];ord-c@1:[];ord-d@1:[sku-5]
reversed: ord-a@1:[sku-1];ord-b@2:[sku-3];ord-c@1:[];ord-d@1:[sku-5]
identical: true
```
