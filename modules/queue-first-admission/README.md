# queue-first-admission

Companion lab for **Article 2 — Black Friday Without a Meltdown**.

A bounded-admission controller and a deterministic discrete-event harness for
measuring what it does under overload.

```bash
make verify
```

28 tests, no cloud project, no credentials, no network, about half a second.

## What this proves, and what it does not

**It is a simulator.** There is no Cloud Run service here, no Spanner instance,
and no load generator. Every number in `results/` is a **simulated result**
from a discrete-event model, and the article labels them that way.

That is a deliberate choice, not a shortcut. A cloud load test produces numbers
that depend on the machine, the region, the day, and the reader's billing
account, and cannot be reproduced at zero cost. The claim this lab supports is
about the *shape* of admission behaviour under overload, which a seeded
simulator demonstrates exactly and repeatably.

What the lab genuinely establishes:

- the admission policy is real code, unit-tested in isolation (T1-T12);
- the invariants hold across load levels (T13-T21);
- each mechanism is necessary, because removing it breaks the property it
  claims (N1-N6).

What it cannot establish: the true contention curve of any Google Cloud
product. See `docs/adr/ADR-002-contention-is-a-model.md`.

## The capacity arithmetic

Everything is expressed against one number:

```text
concurrency 20 slots / mean service 100 ms = 200 completions per second
```

A "2x" scenario offers 400 arrivals per second against that 200/s ceiling.

## Headline results

From `results/experiments.md`, seed 1234. Simulated results.

**Sustained 2x overload (E3).** Same goodput, because goodput is bounded by
capacity in both cases. Everything else differs:

| | Goodput/s | p99 | Abandoned | Rejected |
|---|---:|---:|---:|---:|
| Open loop | 199.42 | 8,427 ms | 10,364 | 0 |
| Bounded | 199.42 | 2,165 ms | 0 | 11,641 |

Admission control did not make the system faster. It cannot. What it did was
convert 10,364 callers who waited eight seconds and then gave up into 11,641
callers who were told "no" immediately, and it kept the promise it made to
everyone it accepted.

**Below capacity (E1).** Bounded and open loop are byte-identical: same
completions, same percentiles, zero rejections. The controller costs nothing
when it is not needed.

**The overload envelope.** With the contention model on, adding worker slots
past the knee buys no throughput and a materially worse tail:

| Worker slots | Goodput/s | p99 |
|---:|---:|---:|
| 20 | 201.78 | 2,175 ms |
| 40 | 203.15 | 2,549 ms |
| 80 | 203.08 | 3,380 ms |
| 160 | 201.40 | 5,015 ms |

Eight times the capacity, no more work done, and the tail nearly doubled. The
coefficient producing that curve is an assumption; the existence of a knee is
the point.

## Layout

```text
src/
  admission.ts    the policy: decide() and the two wait projections
  simulator.ts    discrete-event loop over virtual time
  scenarios.ts    every constant the experiments use
  experiments.ts  the nine experiments and the envelope sweep
  rng.ts          seeded mulberry32; no Math.random anywhere
  metrics.ts      exact nearest-rank percentiles
tests/
  admission.test.ts        T1-T12, the policy in isolation
  invariants.test.ts       T13-T21, properties across whole runs
  negative-control.test.ts N1-N6, remove a mechanism, break a property
docs/adr/         four decision records
results/          generated by `make report`; never edited by hand
```

## Three defects this harness caught in its own design

Recorded because a harness that never contradicted its author was not testing
anything.

1. **Goodput above capacity.** An early run reported 227 completions per second
   against a 200/s ceiling. Completions occurring after the arrival window were
   being divided by the window. Guarded by T15.
2. **An unreachable rule.** The depth backstop was set to 200 while the promise
   rule needed 400 queued jobs to fire, so the promise check was dead code.
   Found by T5, guarded by N5.
3. **Unbounded deferral.** Deferrable work was never refused, so the reservation
   backlog grew without limit and thousands expired — the exact anti-pattern the
   article argues against. Found by E9, guarded by N3 and T11.
